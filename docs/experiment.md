# 创作者激励 A/B 实验方案

## 1. 决策问题

对符合资格的创作者提供激励，是否会增加决策后7天的人均有效内容数，并且不导致内容质量或违规风险恶化？

实验只回答“这套激励策略是否产生增量效果”，不把作者激励后的全部产出归因于激励。

## 2. 样本与时间边界

一行样本表示“一位创作者在一个决策日、一个实验中的状态”，唯一键为：

```text
creator_id + decision_date + experiment_name
```

时间边界：

```text
决策日前7天：计算特征
决策当天：判断资格、随机分组、决定是否发放
决策后7天：观察结果和质量指标
```

字段分层：

| 类别 | 字段 | 决策时是否可用 |
|---|---|---|
| 身份 | creator_id, decision_date | 是 |
| 决策前特征 | posts_last_7_days, active_days_last_7_days, valid_posts_last_7_days, creator_age_days | 是 |
| 实验处理 | experiment_group, incentive_amount, accepted_incentive | 分组/发放时产生 |
| 决策后结果 | future_posts_7_days, future_valid_posts_7_days, active_next_7_days, violation_count | 否，7天后产生 |

决策后结果不能用于当天的规则或预测特征，否则产生时间泄漏。

## 3. 实验对象

候选资格在随机分组前固定，例如：

- 过去7天至少活跃1天；
- 过去7天有效内容数低于预设阈值；
- 没有严重违规；
- 没有参加互斥实验；
- 账号状态允许参加激励。

所有资格条件应在实验开始前写入方案，不能看到结果后临时更换人群。

## 4. 随机化与分组

随机化单位是 `creator_id`：

- `CONTROL`：不发放本次激励；
- `TREATMENT`：提供本次激励；
- 目标分流比例：50:50。

同一作者必须稳定进入同一组，不能因为多次访问而重新随机。若创作者之间存在强互动或机构绑定，还要评估按作者随机是否会发生组间污染。

## 5. 指标体系

### 主指标

决策后7天人均有效内容数：

```text
SUM(future_valid_posts_7_days) / 分组作者数
```

主指标必须在实验前确定，避免从许多结果中挑选偶然显著的一个。

### 辅助指标

- 决策后7天仍活跃的作者比例；
- 决策后7天人均总发布数；
- 激励接受率（只作行为诊断，不替代ITT主指标）。

### 护栏指标

- 内容有效率 = 有效内容数 / 总内容数；
- 违规作者率或违规内容率；
- 删除率；
- 用户负反馈率；
- 每位实验组作者成本；
- 每增加一条有效内容的成本。

主指标上升但护栏明显恶化时，不应直接全量上线。

## 6. 分析方法

主要结论采用 ITT（Intention To Treat）：无论实验组作者是否接受激励，都按照最初随机分组分析。

不能只比较“领取者”和对照组。愿意领取的人可能本来就更活跃，这会产生选择偏差。

核心计算：

```text
绝对提升 = 实验组均值 - 对照组均值
相对提升 = 绝对提升 / 对照组均值
估算增量有效内容 = 实验组人数 × 绝对提升
每条增量有效内容成本 = 实验组总成本 / 估算增量有效内容
```

例子：实验组均值3.2，对照组均值2.6：

```text
绝对提升 = 0.6
相对提升 = 0.6 / 2.6 = 23.1%
```

一位作者收到激励后发了5条，不代表激励带来了5条。若类似对照作者本来会发3条，随机实验估计的增量更接近2条。

## 7. 置信区间与 p 值

均值差只是点估计，还要报告不确定性：

```text
SE = SQRT(实验组方差/实验组人数 + 对照组方差/对照组人数)
95% CI（大样本近似）= 均值差 +/- 1.96 × SE
```

如果95%置信区间包含0，当前数据不足以排除“没有真实提升”。p值是在零假设成立时，得到当前或更极端结果的概率，不是“实验成功的概率”。

练习表只有4位作者，只用于验证查询，不能用于可靠显著性结论。真实实验应在开始前依据基线方差、MDE、显著性水平和检验功效估算样本量。

## 8. 实验质量检查

### SRM

计划50:50却出现70:30等明显偏离，可能表示分流、埋点或入组逻辑故障。应先处理SRM，再解释业务结果。

### 实验前平衡性

对比两组决策前发布数、活跃天数、有效内容数和注册时长。小幅随机差异正常；系统性巨大差异需要检查随机化。

### 多重指标

预先指定一个主指标和有限的护栏指标。若同时检验大量指标，需要调整显著性判断，并完整披露全部检验。

## 9. 运行时间和停止规则

- 每位作者都必须拥有完整的决策后7天观察窗口；
- 实验运行时间应覆盖周内周期，必要时覆盖节假日；
- 不因为中途看到显著结果就提前停止；
- 数据故障、严重护栏恶化或预算风险可触发安全停止；
- 新奇效应可能造成短期提升，应评估更长期留存效果。

## 10. 进阶问题

- MDE：业务上值得检测的最小提升；
- 检验功效：真实效果存在时发现它的概率；
- CUPED：利用实验前相关指标降低方差，但变量必须在处理前产生；
- 网络效应：一个作者的激励可能影响其他作者；
- 组间污染：对照组间接获得实验待遇；
- 分布漂移：节假日、规则变化或作者结构变化导致结论失效。

## 11. 上线决策模板

| 检查项 | 判断标准 |
|---|---|
| 实验完整性 | 无明显SRM、埋点完整、随机化可信 |
| 主指标 | 提升达到业务MDE，并报告置信区间和p值 |
| 护栏指标 | 无不可接受的质量、违规或负反馈恶化 |
| 成本 | 单位增量成本在预算阈值内 |
| 稳定性 | 关键作者分层和时间分段方向基本一致 |

只有实验完整、主指标有业务价值、护栏安全且成本可接受时，才考虑逐步放量。
