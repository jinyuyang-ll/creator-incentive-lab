# 激励效果评估（一页纸）

## 1. 目标

主指标选“决策后7天人均有效内容数”，而不是领取补贴人数。后者只说明激励被领取，不能说明创作真的增加。辅助指标可以是决策后7天仍有有效创作的作者比例。

## 2. 成本

建议同时报告：

- 每位被激励作者的平均成本 = 总激励预算 / 实际被激励作者数；
- 每增加一条有效内容的成本 = 总激励预算 /（实验组有效内容数 - 按对照组估算的自然产出）；
- 每增加一位持续创作者的成本 = 总激励预算 / 两组持续创作人数之差（按样本量标准化后）。

## 3. 对照

从符合资格的作者中随机分组：实验组获得激励，对照组不获得激励，其余体验尽量一致。比较两组决策后7天的平均有效内容数。只观察领取者会有选择偏差：本来就更积极的人更可能领取，也更可能继续发文。

作者收到激励后发了5条，并不代表5条都是激励带来的。反事实“同一个作者没收到激励会发几条”无法直接观察，只能借助随机对照组估计。例如实验组平均5条、可比对照组平均3条，粗略增量才是2条，而不是5条。

## 4. 风险与护栏指标

数量可能上升但质量下降。至少监控有效率（有效内容数/总内容数）、违规率、删除率和用户负反馈率。若主指标上升但护栏指标明显恶化，不应直接全量上线。

实验前还要固定资格条件、随机化单位、观察窗口和停止规则，避免看到短期好结果后提前结束实验。
